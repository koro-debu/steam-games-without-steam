# Denuvo — the full list

Check here **before** trying anything. A game on the first table is decided: no tool in this repo
applies, and the [Denuvo page](../other/Denuvo.md) explains why and what an owner can still do.

Pulled from [PCGamingWiki](https://www.pcgamingwiki.com/)'s structured DRM data on **2026-08-10**,
then every entry with a Steam AppID was re-checked against **Steam's own declaration**
(`appdetails` → `drm_notice`), because the publisher's own store page is the only first-hand
evidence there is. **Re-checked in full on 2026-10-10**: every AppID queried again, and the AppIDs
PCGamingWiki didn't have were looked up on the Steam store by exact name (97 found), which moved
most of the old *Unverified* table into the verified ones. Removals reported on cs.rin.ru's list of
uncracked Denuvo games were cross-checked the same way before being moved.

> **The two sources disagree, and that's the useful part.** Of the 246 entries with a usable AppID

## Redoing this yourself

The whole set comes out of PCGamingWiki's Cargo API in a handful of queries — `Availability.Steam_DRM`,
`Availability.Uses_DRM` and `Availability.Removed_DRM`. Crawling Steam itself is not an option:
roughly 250,000 apps against a store API that tolerates about 200 requests per five minutes.

For a single game, one request settles it:

```bash
curl -s "https://store.steampowered.com/api/appdetails?appids=<APPID>&l=english&cc=us" \
  | grep -o '"drm_notice[^,]*'
```

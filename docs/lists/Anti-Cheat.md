# Anti-cheat — the full list

Check here **before** trying anything. An anti-cheat means stop: nothing in this repo tries to defeat
one, a ban is permanent, and the tools make it worse rather than better — gbe_fork hands the game a
fabricated Steam identity, which is exactly what an anti-cheat is looking for.

**What this list does not say.** It does not say the single-player campaign needs it. Plenty of these
games run their campaign without the anti-cheat ever loading, and playing offline is then a
non-question — see [the rules](../index.md#five-rules-that-apply-to-everything-here). It says: don't
point an emulator at this one.
